# Runtime Shell (`src/shell/`)

Manages the continuous single-source Web Audio API song clock, real-time frequency bands, audio FX, game switcher (`runner -> horror -> tiles -> rail`), hyperspace transition (`READJUST = 1.0s`), safety runway (`RUNWAY = 5.0s`), plain DOM HUD, results screen, playtest hooks (`window.__playtest`), and backtick dev panel.
