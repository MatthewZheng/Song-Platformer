# Analyzed Songs Output (`public/songs/<id>/`)

Each analyzed song folder `<id>` contains:
- `full.mp3`, `demo.mp3` (gitignored audio cuts)
- `full.json`, `demo.json` (complete `SongMap` files)
- `levels/<game>.json` (generated and playtest-tuned level parameters/data for `runner`, `horror`, `tiles`, `rail`)
